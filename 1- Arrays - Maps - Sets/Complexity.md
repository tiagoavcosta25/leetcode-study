## Complexity

| Operation                     | Average Complexity |
|-------------------------------|--------------------|
| Array index search            | O(1)               |
| Array search / ``includes()`` | O(n)               |
| Map / Set lookup              | O(1)               |
| Map / Set insertion           | O(1)               |
| Sorting                       | O(n log n)         |
| Traversing an array           | O(n)               |
